# Tradey Desk Dashboard

Sanitized, static paper-trading audit dashboard prepared for Vercel.

## Deploy on Vercel

1. Import this GitHub repository in Vercel.
2. Leave the framework preset as **Other**.
3. Leave the build command empty.
4. Leave the output directory empty (repository root).
5. Deploy.

No environment variables are required.

## Data updates

`dashboard.json` is a generated snapshot. Push a refreshed `dashboard.json` and `index.html` from the private Tradey Desk system to publish later decision-audit and performance updates. Never publish private reviews, account data, broker order IDs, credentials, prompts, or filesystem paths.
